# Blood Bridge

Blood Bridge is a web-based platform designed to connect patients with suitable blood donors during emergencies. The system allows users to register as donors or patients, patients search for donors based on blood group and location, and submit blood requests, donors submit donation applications.

## Features

* Donor and patient registration
* Blood group-based donor search
* Location-based donor search
* Blood request management
* Secure user login
* Donor information management
* User-friendly and responsive interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap
* Python
* Flask
* MySQL

## Purpose

The main goal of Blood Bridge is to simplify the process of finding blood donors and help patients connect with suitable donors quickly during emergency situations.
